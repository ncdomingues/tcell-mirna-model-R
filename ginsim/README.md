# GINsim network files

The `.zginml` files are the network as drawn in [GINsim](http://ginsim.org) --
nodes, edges, logical parameters and layout. Open them there to see the graph;
the rule tables in `model/` are the same content in the tab-separated form the
R engine reads.

- `my_model_2017.zginml` -- the network without the miRNAs
- `my_model_2017_mirs34_155.zginml` -- with miR-34c-5p and miR-155-5p added
- `my_model_2017_mirs34_155_8_2_17.zginml` -- the 8 February revision

GINsim is not required to run anything in this repository.
